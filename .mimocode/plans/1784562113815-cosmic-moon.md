## File 2: `docs/DECISIONS.md`

Add 4 new ADRs with status "پیشنهاد" (proposed):

**ADR-005:** Local notes with SQLite + FTS5
- Context: Zero Notes needs fast Persian full-text search; all data must stay local
- Decision: SQLite with FTS5 extension for notes table, encrypted with existing crypto.rs
- Consequences: No server dependency for notes; FTS5 handles Persian tokenization well enough

**ADR-006:** Translation service behind gateway
- Context: Simultaneous translation (fa↔en) requires an external provider; keys must stay server-side per ADR-003
- Decision: Add a TranslationProvider trait behind the gateway (same pattern as STT), with its own quota key `quota:translate:{userId}:{yyyymm}`
- Consequences: Quota system extends cleanly; provider can be swapped (DeepL, Google, OpenAI)

**ADR-007:** Meeting mode with file import + LLM summary
- Context: Long recordings (30-60 min) need buffered processing; summary requires LLM (server-side)
- Decision: Extend existing buffer.rs for segmented encrypted chunks; LLM summary as optional Pro feature via server gateway
- Consequences: Depends on Phase 8 (notes) for storage; LLM cost must be tracked in quota

**ADR-008:** v1 scope expansion — Chapter 2 features
- Context: CLAUDE.md explicitly excludes personal dictionary, snippets, voice commands beyond minimal, and LLM polish from v1. User has confirmed these as Phase 2 growth features.
- Decision: Add Chapter 2 (Phases 8-12) to TASKS.md. These features are NOT built in v1 branches. They begin only after v1 core (Phases 0-7) is complete and each ADR (005-008) is confirmed.
- Consequences: Clear separation; v1 remains focused; architecture already supports extension points per spec §2.
