# PRODUCT-STORY.md — چشم‌انداز محصول Zero

شعار: «هرجا می‌توانی تایپ کنی، می‌توانی صحبت کنی.»

Zero یک نرم‌افزار نیست؛ یک لایه ورودی برای ویندوز است — مثل کیبورد و ماوس. کاربر نباید حس کند برنامه‌ای باز کرده؛ باید حس کند ویندوز خودش قابلیت شنیدن پیدا کرده است.

## سه فصل محصول
1. **Zero Core (نسخه ۱):** میانبر → صحبت → درج/کپی هوشمند. سبک، نامرئی، همیشه آماده.
2. **Zero Smart (فاز ۲):** صیقل متن (نیم‌فاصله، نگارش، لحن متناسب با برنامه مقصد)، واژه‌نامه شخصی، Draft Mode برای دیکته طولانی.
3. **Zero Flow (فاز ۳):** فرمان‌های صوتی برای کنترل ویندوز.

## رفتارهای کلیدی UX
- درج هوشمند: مقصد قابل‌تایپ → درج مستقیم؛ نبود → Clipboard + «کپی شد ✓». کاربر سوییچ نمی‌کند، Zero می‌فهمد.
- زبان بدن: دایره ۳۶px کنار Cursor — آبی نبض‌دار (شنیدن)، زرد چرخان (تبدیل)، سبز (موفق)، قرمز (خطا؛ تنها حالت با متن).
- قول اصلی: هیچ صحبتی هرگز گم نمی‌شود.
- حالت‌های تعامل: Tap-to-Talk و Push-to-Talk. Silent Mode پیش‌فرض.
- Onboarding سی‌ثانیه‌ای: انتخاب میانبر → تست زنده → تمام. لحظه «آها!» باید در ۳۰ ثانیه اول رخ دهد.

## تمایز رقابتی
فارسی‌نویسی حرفه‌ای (نیم‌فاصله، رسم‌الخط، نگارش) و درج سالم RTL — چیزی که رقبای جهانی (Wispr Flow, SuperWhisper) ندارند. این خندق محصول است.

## مدل کسب‌وکار
فریمیوم: Core رایگان (محلی نامحدود + ۳۰ دقیقه ابری در ماه)، Smart اشتراکی (ابری نامحدود + لایه صیقل). مخاطب: عمومی، همه مشاغل.

## سنجه موفقیت
کاربر پشت کامپیوترِ بدون Zero می‌نشیند، میانبر را می‌زند، اتفاقی نمی‌افتد — و کلافه می‌شود.
