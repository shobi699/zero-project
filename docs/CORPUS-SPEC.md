# مشخصات مجموعه تست صوتی (Corpus Spec)

## هدف
ارزیابی دقت، تأخیر و هزینه Providerهای STT ابری برای فارسی، پیش از انتخاب دو Provider اول برای Gateway.

## دسته‌بندی نمونه‌ها

هر دسته حداقل ۳ فایل صوتی (۵–۳۰ ثانیه) با متن مرجع دارد:

### ۱. فارسی محاوره (`colloquial-*.wav`)
- گفتار روزمره، سرعت عادی
- شامل عبارات شکسته و محاوره‌ای
- مثال: «الان دارم میرم خونه، یه ربع دیگه میرسم»

### ۲. فارسی رسمی (`formal-*.wav`)
- نثر رسمی/اداری/خبری
- جملات بلندتر، واژگان تخصصی‌تر
- مثال: «بر اساس گزارش سازمان هواشناسی، دمای هوای تهران به چهل درجه سانتی‌گراد خواهد رسید»

### ۳. مخلوط فارسی-انگلیسی (`mixed-*.wav`)
- کد-سوییچینگ طبیعی فارسی-انگلیسی
- اصطلاحات فنی انگلیسی در جمله فارسی
- مثال: «توی VS Code یه extension جدید نصب کردم برای debugging»

### ۴. اسامی خاص (`names-*.wav`)
- نام اشخاص، مکان‌ها، برندها
- ترکیب نام‌های فارسی و خارجی
- مثال: «جلسه با آقای محمدی ساعت سه در دفتر مایکروسافت»

## فرمت فایل‌ها
- صوت: WAV، ترجیحاً 16kHz mono PCM (هارنس ریسمپل می‌کند اگر متفاوت باشد)
- مرجع: فایل `.txt` هم‌نام با فایل WAV (مثلاً `colloquial-01.wav` ↔ `colloquial-01.txt`)
- متن مرجع: نگارش صحیح فارسی با نیم‌فاصله و نشانه‌گذاری کامل

## نکات ضبط
- میکروفون معمولی لپ‌تاپ یا هدست (نه استودیویی — شبیه شرایط واقعی)
- محیط با نویز پس‌زمینه متوسط قابل قبول
- هر فایل یک گوینده
- طول هر فایل: ۵ تا ۳۰ ثانیه

## معیارهای ارزیابی
- **WER** (Word Error Rate): نرخ خطای کلمه
- **CER** (Character Error Rate): نرخ خطای نویسه
- **Latency**: زمان پاسخ از ارسال تا دریافت متن نهایی
- **Cost**: هزینه به ازای هر دقیقه صوت (USD)

## آستانه‌های پذیرش (پیشنهادی)
- WER فارسی محاوره: < ۱۵٪
- WER فارسی رسمی: < ۱۰٪
- WER مخلوط: < ۲۰٪
- Latency (P95): < ۳ ثانیه برای فایل ۱۰ ثانیه‌ای
